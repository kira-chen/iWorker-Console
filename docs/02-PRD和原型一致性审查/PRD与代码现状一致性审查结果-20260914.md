## 一、C类差异（代码未跟进md）

### C1. 【中】专家/技能/模型 — 状态列独立显示与 PRD 不一致

**位置**：三模块列表页  
**PRD 原文**：
- 专家 §二.1："专家名：展示图标、专家名称和状态标签【未发布】【审核中】【已发布】；不设独立状态列"
- 技能 §二.1："技能名：展示图标、技能名称和状态标签；名称超长换行完整展示，**不设独立状态列**"
- 模型 §二.1："模型名称：列表只展示管理员设置的模型名称，不展示模型标识"

**代码实现**：
- `AdminExperts.vue:349-352`：专家名与状态拆成两列（名称列 + 独立状态列），注释标注"2026-09-11按《列表页UI.png》把状态标签拆回独立列"
- `AdminSkillsUnified.vue:593-597`：技能名与状态拆成两列，注释标注"2026-09-11按《列表页UI.png》把三态状态标签拆回独立列"
- `AdminModels.vue:524-528`：模型名与状态拆成两列，注释标注"2026-09-11按《列表页UI.png》把状态标签拆回独立列"

**差异性质**：PRD 明确描述"不设独立状态列"，代码按 2026-09-11 视觉规范统一改为独立列，三模块代码注释均标注了同一依据《列表页UI.png》，但 PRD 文字稿未同步更新。

**建议**：确认《列表页UI.png》是否为当前视觉规范，若是则 PRD 需同步更新三模块的"状态列独立显示，紧跟名称列之后"描述；若 PRD 为准则需回退代码。
