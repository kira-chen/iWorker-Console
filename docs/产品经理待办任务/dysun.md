# 孙丹阳（dysun · GitHub Diana37-bot）的待办

> 用法：任何人发现**需要 孙丹阳 处理**的事项，往「待处理」表追加一行（序号 = 两表现有最大序号 + 1，状态填「未处理」）。
> 处理完后**不要手改这份文件**——在完成那次 commit 的说明里写 `关闭待办 dysun#序号`（或 `closes dysun#序号`），
> post-commit 钩子会自动把该行搬到「已处理」表并并入本次提交；CI 会核验搬没搬。
> 问题详述要写清：现状 / 依据（md 章节或 commit）/ 期望结果，让人不用回头找上下文就能动手。
> 追加前先 `git pull`，避免序号撞车；撞了以先合入 main 的为准，后者改号。
