# 各模块必填/选填字段一览表

> 依据各模块 PRD 整理。字数限制统一规则：**名称类字段最多 64 字符，简介/描述类字段最多 2000 字符**。版本管理提交时的「升级说明」单列在末尾。

---

## 一、岗位

| # | 字段 | 必填 | 说明 |
|---|------|------|------|
| 1 | 岗位名称 | ✅ | 最多 64 字符 |
| 2 | 图标 | ✅ | — |
| 3 | 岗位描述 | ✅ | 最多 2000 字符 |

> **发布前置条件**：至少关联 1 个岗位私有技能。

## 二、专家

| # | 字段 | 必填 | 说明 |
|---|------|------|------|
| 1 | 专家名 | ✅ | 最多 64 字符，占位"如 经营分析专家" |
| 2 | 专家分类 | ✅ | 下拉选择（通用/法律/财税/政务/供应链/投资/审计/知识产权） |
| 3 | 图标 | ✅ | — |
| 4 | 简介 | ✅ | 最多 2000 字符，占位"一句话说明该专家能解决什么问题" |
| 5 | 职责描述 | ✅ | 最多 2000 字符，Markdown 编辑器（加粗/斜体/列表/表格），右下角字数统计 |
| 6 | 专家帮你做（示例问题） | ✅ | 固定 3 条输入行 |
| 7 | 技能绑定 | ✅ | 至少引用 1 个市场技能 |

> **发布前置条件**：至少引用 1 个市场技能。
> **校验**：专家名、分类、图标、简介、职责描述、示例问题必填，至少引用 1 个市场技能。

## 三、技能

| #   | 字段          | 必填  | 说明                                               |
| --- | ----------- | --- | ------------------------------------------------ |
| 1   | 技能名称        | ✅   | 最多 64 字符                                         |
| 2   | 技能分类        | ✅   | 下拉选择（办公效率/智能创作/数据分析/开发编程/IT运维与安全/行业专业/知识与学习/其他）  |
| 3   | 图标          | ✅   | —                          |
| 4   | 描述          | ✅   | 多行输入，最多 2000 字符并显示字数统计；占位"描述这个技能能做什么、怎么用、适合什么场景" |
| 5   | 示例问题        | ✅   | 1 条，最多 60 字符；输入框旁有【AI 生成】按钮，按钮使用常规字重，点击调用模型生成，重复点击重新生成 |
| 6   | 默认安装        | 选填  | 复选框，仅平台支持时展示                                     |
| 7   | SKILL.md 正文 | ✅ 发布前 | 编辑器内编写；须存在且正文非空，缺失或为空时【发布】置灰                      |
| 8   | 工具引用        | 选填  | 从连接器工具列表中选择插入                                    |

> **上传方式**：默认不展示技能分类；选择或拖入一个或多个 .zip 包（须含 SKILL.md）后，每个技能包分别选择技能分类再导入。导入成功后返回列表，仅展示一次性轻提示，不保留提示条、标签、行高亮或编辑按钮强调样式。手动创建空白技能时展示技能类型、技能分类和技能名称，创建后直接进入技能编辑页，描述、示例问题与 SKILL.md 正文默认为空。`技能名称 + 技能类型 + 技能分类 + 图标 + 描述 + 示例问题 + 非空 SKILL.md` 全部满足后才可发布，否则列表页和编辑页【发布】均置灰并提示待补齐项。

## 五、MCP 连接器

### 5.1 基本信息

| #   | 字段   | 必填  | 说明                                 |
| --- | ---- | --- | ---------------------------------- |
| 1   | 名称   | ✅   | 最多 64 字符，占位"如 报销系统 MCP"            |
| 2   | 图标   | ✅   | —            |
| 3   | 服务描述 | ✅   | 最多 2000 字符，占位"一句话说明这个 MCP 服务是做什么的" |
| 4   | 示例问题 | ✅   | 固定 3 条输入行                          |

### 5.2 传输与连接

| # | 字段 | 必填 | 说明 |
|---|------|------|------|
| 4 | 传输方式 | ✅ | stdio 或 streamable-http（默认） |
| 5 | 超时时间 | ✅ | 默认 10000 ms，范围 1000~120000，步长 1000 |

**传输方式 = streamable-http 时：**

| # | 字段 | 必填 | 说明 |
|---|------|------|------|
| 6 | MCP 服务地址（Endpoint） | ✅ | 须以 http:// 或 https:// 开头 |
| 7 | Bearer Token | ✅ 新配置时 | 不含 Bearer 前缀 |
| 8 | Header 名 | ✅ 选 API Key 时 | 最多 128 字符，仅字母/数字/连字符 |
| 9 | 访问凭证 | ✅ 选 API Key 时 | 新配置时必填 |

**传输方式 = stdio 时：**

| # | 字段 | 必填 | 说明 |
|---|------|------|------|
| 6 | Command | ✅ | 占位"npx"，仅命令名称 |
| 7 | Arguments | 选填 | 多行输入，每行一个参数 |
| 8 | Environment | 选填 | 多行输入，每行一个名称和值 |

> **注**：Header 名为技术标识符字段，不适用名称的统一字数限制。
> **登记**：填完后点【登记】，系统连接 MCP 服务并自动拉取工具列表。

## 附：字数限制统一规则

| 字段类别 | 统一限制 | 说明 |
|----------|----------|------|
| **名称类**（各模块的名称/标题字段） | 最多 64 字符 | 岗位名称、专家名、技能名称、模型名称、MCP 名称、API 名称、系统名称、角色名称 |
| **描述类**（简介、描述、职责描述等） | 最多 2000 字符 | 岗位描述、专家简介、职责描述、技能简介、技能描述、模型描述、MCP 服务描述、API 描述、系统描述、升级说明 |
| **技术配置类**（URL、标识符、JSON） | 按字段单独设定 | base_url 最多 500 字符、模型标识最多 200 字符、Header 名最多 128 字符、额外参数最多 2000 字符 |
| **示例类** | 按字段单独设定 | 示例问题最多 60 字符 |
