# 岗位管理产品需求

## 一、产品目标与入口

岗位管理以用户为核心维护"用户—岗位"一对一绑定关系，保存后即时生效；同时支持处理用户从客户端提交的岗位申请（待分配申请）。

- **页面入口**：侧边栏"02 岗位 / 岗位管理"。
- **页面标题**：岗位管理。
- **页面说明**：管理用户岗位绑定，分配岗位或处理待分配申请。
- **权限要求**：无页面权限时不展示入口。

## 二、查询区与工具栏

工具栏从左到右展示：

1. **搜索框**：占位"搜索用户名 / 显示名"，支持用户名、显示名模糊搜索；输入停顿（220ms）后自动刷新列表，**不重置分页**，保留当前页码。
2. **状态筛选**：全部状态、启用、停用；切换后自动刷新列表，**不重置分页**，保留当前页码。
3. **待分配申请**按钮：点击后仅展示有待分配申请的用户，再次点击恢复全量；按钮右侧以数量徽标展示当前待处理申请数，数量为 0 时不展示徽标。激活态按钮以主题色高亮区分。
4. **查询按钮**：按当前搜索词和状态筛选刷新列表，并**回到第 1 页**。
5. **批量绑定**按钮（右侧）：勾选用户后激活，未勾选时置灰；按钮右侧展示已勾选用户数；点击后打开批量绑定弹窗。

搜索和状态可以组合使用。

## 三、用户列表

### 3.1 展示字段

| 字段 | 展示规则 |
| --- | --- |
| 勾选框 | 用于多选，配合批量绑定使用 |
| 用户名 | 用户登录名，使用强调字重 |
| 显示名 | 用户显示名称；无内容显示"—" |
| 状态 | 启用为绿色标签，停用为灰色标签 |
| 绑定岗位 | 展示当前岗位名称；无岗位显示"未绑定"；有待分配申请时在岗位名称后附"待分配"橙色标签 |
| 操作 | 固定展示【分配岗位】 |

列表根据页面可用高度动态计算每页条数，最少 5 条、最多 30 条；底部展示总条数、每页条数和分页器。

### 3.2 状态说明

- 停用用户仍保留原岗位绑定关系，管理员可修改或清除绑定。
- "待分配"标签：该用户已从客户端提交岗位申请但尚未处理时展示，提示管理员待分配操作。

### 3.3 分配完成后的置顶高亮

管理员为某用户完成分配岗位操作后，若该用户有待分配申请，系统自动清空搜索和状态筛选，将该用户置顶显示并以高亮行样式聚焦，便于管理员确认操作结果；下次主动查询或翻页后取消高亮。

## 四、分配岗位

### 4.1 单个分配

点击行内【分配岗位】打开"分配岗位"弹窗。

弹窗规则：

- 顶部提示"为 显示名 选择绑定岗位，保存后即时生效"。
- **绑定岗位**为单选下拉框，展示已发布及审核中的岗位（审核中指已发布岗位在审新版或停用审核，其已发布版本持续可用）；首项为"未绑定"，用于清除绑定。
- 默认选中用户当前绑定岗位。
- 换绑提示：换绑会清除该用户在原岗位上的个性化（岗位人格 / 搭子名称）；会话、记忆、定时任务保留不变。
- 点击【保存】后更新绑定关系、关闭弹窗，并执行置顶高亮流程（见 §3.3）；提示"岗位绑定已更新"。
- 点击【取消】、关闭按钮或遮罩，放弃本次修改。

### 4.2 批量绑定

勾选一名或多名用户后点击【批量绑定】打开批量绑定弹窗。

弹窗规则：

- 顶部展示"已选 N 名用户，请选择要统一绑定的岗位"。
- **岗位选择**为单选下拉框，展示已发布及审核中的岗位，支持搜索过滤。
- 确认前弹出二次确认，说明将统一绑定至哪个岗位、涉及哪些用户。
- 确认后逐个更新绑定关系，全部完成后提示"已将 N 名用户绑定至「岗位名」"，清除勾选并刷新列表。
- 点击【取消】关闭弹窗，不执行任何绑定操作。

## 五、待分配申请处理

当用户从客户端提交岗位申请后，该用户在列表"绑定岗位"列展示"待分配"橙色标签，并计入工具栏"待分配申请"按钮的数量徽标。

管理员通过以下方式处理：

1. 点击工具栏【待分配申请】按钮，筛选出所有有待分配申请的用户。
2. 点击该用户行内【分配岗位】，在弹窗中选择合适岗位并保存。
3. 保存后系统自动标记该申请为已处理（已分配），徽标数量减少，用户置顶高亮。

## 六、业务规则

- 每个用户同一时间最多绑定 1 个岗位。
- 换绑为覆盖关系，不保留多个并行岗位。
- 可绑定岗位包括"已发布"及"审核中"岗位；未发布岗位（含首次发布审核中）不进入下拉选项。
- 用户停用不自动解除岗位绑定。
- 清除绑定只解除岗位关系，不删除用户，不影响历史会话、记忆与定时任务。
- 批量绑定与单个分配均允许将用户绑定至任意已发布及审核中的岗位，无需与申请岗位一致。

## 七、异常与空状态

| 场景 | 页面处理 |
| --- | --- |
| 查询无结果 | 展示"没有匹配的用户"，保留条件 |
| 待分配筛选无结果 | 展示"暂无待分配申请"，保留筛选条件 |
| 无可绑定岗位 | 分配岗位弹窗下拉框仅展示"未绑定" |
| 保存失败 | 弹窗保持打开并展示失败原因 |
| 绑定岗位在保存前被停用 | 阻止保存并刷新可选岗位 |
| 无操作权限 | 【分配岗位】置灰或不展示 |
