# 驾驶舱产品需求

## 一、页面入口与页头

### 1. 功能说明

驾驶舱是管理后台的全局概览页，帮助管理员快速掌握数字员工资产的发布情况、岗位领用规模与治理待办，无需逐个模块查找。

- **页面入口**：侧边栏"01 总览 / 驾驶舱"。总览段定位为全后台概览，三后台角色（FDE 工程师 / 系统配置员 / ADMIN）均可见。
- **页面标题**：展示"驾驶舱"。
- **页面说明**：文案"查看数字员工资产、岗位领用、任务运行和治理待办。"
- **更新时间**：页头右侧展示"更新于 HH:MM"（24 小时制，精确到分钟）。
- **刷新按钮**：【刷新】，点击后重新拉取全页数据。

### 2. 交互规则

- 点击【刷新】：页面整体进入加载态（指标卡文字、待办卡片、表格行呈灰色骨架屏动效，约 650ms），期间内容不可点击；完成后"更新于"时间刷新为当前时刻，并 toast 提示"驾驶舱数据已刷新"。
- 页面所有数据均为静态示例数据，用于演示布局与交互，不代表生产环境实际值。

## 二、核心指标卡区

### 1. 卡片布局

6 个指标位按 4 列栅格排列为两行：

- **第一行**：已发布岗位数量、领用岗位员工数量、已发布技能数量、已发布专家数量——均为同一样式（圆环卡），各占 1 列。
- **第二行**：知识资产（双格卡）、待处理（危险色卡）——各占 2 列（宽卡），左右平分整行。

### 2. 圆环卡（已发布岗位数量 / 领用岗位员工数量 / 已发布技能数量 / 已发布专家数量）

- **卡头**：左侧指标名称，右侧软色标签（"已发布" / "覆盖率"）。
- **主体**：左侧数值 + 单位（如"14 个"），右侧圆环进度——环内文字为精确占比（整数占比不带小数，如"78%"；非整数占比精确到小数点后一位，如"89.9%"），环形弧长按整数四舍五入呈现（视觉上与文字可能相差 0 ~ 1 个百分点，如弧长 90% 对应文字 89.9%）。
- **副文案**：展示对比基数，如"全部岗位 18 个"。
- **点击**：整卡可点击，toast 提示"正式系统中将进入「指标名称」"。

示例取值：

| 指标 | 数值 | 环内文字 | 副文案 |
| --- | --- | --- | --- |
| 已发布岗位数量 | 14 个 | 78% | 全部岗位 18 个 |
| 领用岗位员工数量 | 241 人 | 89.9% | 启用员工 268 人 |
| 已发布技能数量 | 68 个 | 82.9% | 全部技能 82 个 |
| 已发布专家数量 | 18 个 | 81.8% | 全部专家 22 个 |

### 3. 知识资产卡（双格，宽卡占 2 列）

- **卡头**：标签"资产构成"。
- **主体**：左右两格分别展示"知识库"数量与"数据源"数量（如 12 / 19），格子左侧带强调色竖线。
- **副文案**："点击查看知识资产明细"。
- **点击**：整卡可点击，toast 提示"正式系统中将进入「知识库」"。

### 4. 待处理卡（危险色，宽卡占 2 列）

- **卡头**：标签"需处理"，顶部色条与标签均为危险色（区别于其他卡片的强调色）。
- **主体**：待处理总数（如"16 项"）。
- **分项**：横向展示三类分项数量——待审核、高风险、连接失败；待审核用警告色，高风险 / 连接失败用危险色。
- **点击**：整卡可点击，toast 提示"正式系统中将进入「待处理事项」"。

## 三、异常与待办

### 1. 功能说明

以卡片形式集中展示当前需要人工介入的待办事项，帮助管理员优先处理。

- **区块标题**："异常与待办"，右侧展示"共 N 项"（N 为下方全部卡片数量之和）。
- **卡片字段**：来源模块（如"审核中心"）、严重度标签（"待审核" / "连接失败" / "高风险"，前置圆点）、数量、说明文案、行动按钮（如"去审核" / "去处理"）。
- **严重度样式**：中风险（待审核）为警告色左边框；高风险（连接失败、高风险技能）为危险色左边框。

示例数据：

| 来源 | 严重度 | 数量 | 说明 | 行动 |
| --- | --- | --- | --- | --- |
| 审核中心 | 待审核（中） | 11 | 发布审核 7 / 版本发布 3 / 停用审核 1 | 去审核 |
| 连接器 | 连接失败（高） | 3 | MCP 2 / API 1 | 去处理 |
| 用户技能审核 | 高风险（高） | 2 | 等待人工审核 | 去审核 |

### 2. 交互规则（2026-09-17 裁决：由 toast 占位改为真实跳转）

- 三张卡片横向等宽排列；点击卡片内的行动按钮，**跳转到对应模块页面**处理，不再是 toast 占位：
  - "审核中心"卡【去审核】→ 跳转审核中心页面（`UnifiedReview`）。
  - "连接器"卡【去处理】→ 跳转连接器页面（`AdminConnector`）。
  - "用户技能审核"卡【去审核】→ 跳转用户技能审核页面（`SysConfigUserSkillReviews`）。
- 卡片本身不可点击，仅行动按钮响应点击。

## 四、各模块发布状态与岗位领用 Top 5

两个面板并排展示（窄屏下改为上下堆叠）。

### 1. 各模块发布状态

- **图例**：右上角展示三色图例——已发布（强调色）、审核中（橙色）、未发布（灰色）。
- **列表行**：按模块展示——岗位、专家、技能、MCP、API、业务系统、模型、知识库，共 8 行。
- **每行字段**：模块名称、总数、三色堆叠条（按已发布 / 审核中 / 未发布占比分段，精确到小数点后一位）、明细计数（已发布 / 审核中 / 未发布，如"14 / 2 / 2"）。不提供跳转操作（2026-09-17 裁决：删去本行【查看】按钮）。

### 2. 岗位领用 Top 5

- **展示范围**：只展示状态为"已发布"的岗位（2026-09-17 裁决）；未发布 / 审核中的岗位不进入本榜单排名。
- **表格列**：岗位（含排名号 + 名称 + 版本号 + 状态）、领用人数（横向进度条，按 Top 5 中最大领用人数归一化）、技能数、Agent 数。不提供跳转操作（2026-09-17 裁决：删去本行【查看】按钮）。
- **排名号**：前 3 名（Top 3）用强调色高亮，其余用灰色。

## 五、用户端点踩统计

本模块只聚焦"点踩"这一件事——总量与趋势，是驾驶舱通往第六、七节"点踩上下文明细"两个弹窗的入口；不展示点赞数据，也不再按岗位拆分分布（2026-09-17 负责人裁决：模块收窄为点踩统计 + 点踩上下文明细，更轻量；原"按岗位分布"表格及其岗位筛选一并删去）。

### 1. 总览统计

- **区块头**：标题"用户端点踩统计"，副标题"每轮对话均可反馈"，右侧【查看点踩明细】【导出报表】两个按钮。
- **两格统计卡**：
  1. 点踩总数 + 点踩率 + 点踩率进度条（危险色）。
  2. 本月点踩趋势（如"↓ 3.1% 较上月"）+ 上月点踩率对比文案（如"上月点踩率 15.3%，持续改善"）。

### 2. 交互规则

- 【导出报表】：toast 提示"正式系统中将进入「反馈报表」"（占位，暂无实际导出）。
- 【查看点踩明细】：打开"点踩明细"弹窗（见第六节）。

## 六、点踩明细弹窗

### 1. 打开方式

- 顶部【查看点踩明细】：打开弹窗，展示全部点踩明细样例记录（不再支持按岗位预筛，见第五节说明）。

### 2. 弹窗结构

- **标题栏**：标题"点踩明细记录" + "共 N 条"。
- **筛选行**：
  - **时间范围**：下拉选择"近 7 天 / 近 30 天（默认） / 近 90 天"，当前版本仅作展示，不影响列表结果。
  - **导出 CSV**：点击后 toast 提示"已生成点踩明细 CSV，正在下载…"（占位，暂无实际文件下载）。
- **表格列**：时间（精确到分钟）、岗位、用户（脱敏，如"张\*\*"）、对话内容摘要（单行省略，悬停查看完整内容）、操作（【查看】）。
- **分页**：每页 10 条，底部展示"第 X / Y 页，共 N 条"及【上一页】【下一页】；到达首 / 末页时对应按钮置灰禁用。

### 3. 数据说明

- 示例数据集含 52 条抽样明细，代表统计卡片中"1,031 次点踩"的样例子集，用于交互演示，非逐条对应生产数据。

### 4. 操作

- 行内【查看】：关闭当前"点踩明细"弹窗，打开"对话明细"弹窗（见第七节），展示该条点踩记录的对话上下文。

## 七、对话明细弹窗

### 1. 打开方式

- 从"点踩明细"弹窗表格行内【查看】打开，两个弹窗互斥（打开对话明细时点踩明细自动关闭）。

### 2. 弹窗结构

- **标题栏**：标题"对话明细" + 记录编号（如"D-1031"）。
- **元信息**：岗位、用户、点踩时间三项，横向展示。
- **对话气泡列表**：还原该次点踩前后的完整对话片段，共 6 轮——
  1. 两轮铺垫问答（用户提问 + 助手回复）。
  2. 用户发出触发本次点踩的问题（对应点踩明细表格中的"对话内容摘要"）。
  3. 助手给出的回复（即被点踩的那一轮）。
- **气泡样式**：用户消息右对齐、强调色底白字；助手消息左对齐、白底描边；被点踩的助手消息额外用暖色描边 + 浅色底，并在时间戳旁附"点踩"标签。
- 每条消息下方展示发送时间（精确到分钟）。

### 3. 操作

- 【关闭】：关闭弹窗，返回驾驶舱主页面（不回退到点踩明细弹窗）。

## 八、异常场景

- **加载 / 刷新中**：指标卡、异常待办列表、各类表格行呈灰色骨架屏动效，暂不可交互；无独立的加载失败态（demo 静态数据，恒定成功）。
