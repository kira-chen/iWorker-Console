# 知识库产品需求文档

## 一、文档说明

### 1. 目标

知识库用于统一管理企业、专家和岗位的知识来源。平台既支持上传文档进入平台 RAG，也支持通过 API 或 MCP 接入第三方知识服务，并为岗位和专家提供可控、可验证的检索能力。

### 2. 范围

本文覆盖管理端“知识库”模块的以下页面和交互：

- 知识库管理列表；
- 知识库新建、编辑、查看及发布/停用审核；
- 数据源管理列表；
- 上传、API、MCP 三类数据源配置；
- 上传文档管理；
- 知识库检索测试。

### 3. 权限

- 适用角色：SYS_CONFIG、ADMIN。
- 无权限用户不可进入知识库页面，也不可通过接口执行新增、编辑、删除、发布、停用和测试操作。

---

## 二、页面框架

### 1. 页面入口

- 管理端导航进入“知识库”，路由为 `/admin/knowledge-base`。
- 页面标题：知识库。
- 页面说明：集中管理企业、专家和岗位知识来源，可将文件上传至平台 RAG，或通过 API、MCP 接入第三方知识服务。

### 2. 顶部页签

页面展示两个页签：

1. **知识库管理**：管理知识库的范围、数据源引用、状态和发布流程；地址参数为 `?tab=kb`。
2. **数据源管理**：维护上传、API、MCP 数据源及其连接配置；地址参数为 `?tab=source`。

- 切换页签时同步更新地址参数，刷新页面后保留当前页签。
- 页签内容采用缓存，返回时尽量保留用户已输入的查询条件和分页位置。

## 三、知识库管理

### 1. 列表筛选

| 筛选项 | 规则 |
|---|---|
| 关键词 | 按知识库名称模糊查询。 |
| 知识库类型 | 全部、企业知识库、专家知识库、岗位知识库。 |
| 状态 | 全部、未发布、审核中、已发布。 |

- 点击【查询】执行筛选；筛选变化后从第 1 页展示。
- 页面右上角展示【新建知识库】。

### 2. 列表字段

| 字段 | 展示规则 |
|---|---|
| 知识库名称 | 展示名称；点击进入编辑或查看。 |
| 类型 | 企业、专家或岗位。 |
| 数据源 | 按已引用的数据源类型汇总展示"上传 ×N / API ×N / MCP ×N"；无引用显示"—"。 |
| 文档数 | 展示该知识库引用的上传数据源的文档总数；无引用上传数据源显示"—"。 |
| 可见范围 | 企业知识库展示"全员"；专家、岗位知识库展示已选择的专家或岗位。 |
| 状态 | 展示未发布、审核中、已发布。待发布和待停用统一展示"审核中"，不额外增加列表状态。 |
| 操作 | 【查看】【编辑】为固定操作；审核中追加【撤回】；未发布追加【发布】【删除】；已发布追加【停用】【检索测试】。 |

- 列表支持分页。
- 加载中展示表格加载状态；失败展示错误原因和重试；无数据展示空状态，不用空白表格表达。

### 3. 新建与编辑抽屉

- 新建、编辑采用右侧抽屉，建议宽度 720px。
- 抽屉区分可编辑和只读状态；审核中配置锁定，仅允许查看或撤回。

#### 3.1 基本信息

| 字段 | 必填 | 规则 |
|---|---:|---|
| 知识库名称 | 是 | 最多 100 个字符。 |
| 知识库类型 | 是 | 企业、专家、岗位；创建后不可修改。 |
| 可见范围 | 是 | 企业类型固定为全员；专家类型选择专家，创建后不可更改；岗位类型选择岗位。 |
| 描述 | 是 | 最多 500 个字符，"必填：这个知识库放什么、给谁用"。 |

#### 3.2 数据源引用

- 分别支持选择上传、API、MCP 数据源；每一类最多引用 5 个。
- 候选项来自“数据源管理”中已创建的数据源；此处只做引用，不在知识库抽屉内重复创建或编辑数据源。
- **候选项仅包含“启用”状态的数据源，已停用的数据源不出现在候选列表中，不可被引用**（2026-09-09 负责人拍板）。
- 相应地，**数据源被知识库引用时不允许停用**，需先在引用它的知识库里解除引用才能停用（与“被引用不可删除”同一口径，见 §四.2）；因此不存在“已停用但仍被引用”的数据。
- 上传数据源没有解析成功文档、API/MCP 尚未验证或验证失败时，显示风险提示。

### 4. 状态与操作

#### 4.1 编辑抽屉底部按钮

| 当前状态 | 底部操作 |
|---|---|
| 新建 | 取消、保存。 |
| 未发布 | 删除、取消、保存、提交发布。 |
| 审核中 | 关闭、撤回。配置只读。 |
| 已发布 | 取消、保存。 |

#### 4.2 查看抽屉底部按钮

| 当前状态 | 底部操作 |
|---|---|
| 审核中 | 关闭、撤回。 |
| 未发布 | 关闭、提交发布。 |
| 已发布 | 关闭。 |

#### 4.3 列表行内操作确认弹窗

列表中点击【发布】【停用】【撤回】【删除】均弹出确认弹窗：

| 操作 | 弹窗标题 | 弹窗内容 | 确认按钮文本 | 成功后 |
|---|---|---|---|---|
| 提交发布 | 提交发布 | 提交后进入审核流程，审核通过后对可见范围生效。确认提交？ | 提交发布 | 状态变为审核中，toast「已提交发布，等待审核」 |
| 提交停用 | 提交停用 | 提交停用后进入审核，审核通过前该知识库对可见范围仍然生效。确认提交？ | 提交停用 | 状态变为审核中，toast「已提交停用，等待审核」 |
| 撤回 | 撤回提交 | 撤回本次提交后将回到修改前状态。确认撤回？ | 撤回 | 状态变为未发布，toast「已撤回」 |
| 删除 | 删除知识库 | 删除后配置无法恢复，确认删除？ | 删除 | 从列表移除，toast「知识库已删除」 |

- **保存**：仅保存配置，不向使用方开放。
- **提交发布**：通过完整校验后进入审核中；审核通过变为已发布。
- **提交停用**：已发布知识库提交后进入审核中；审核通过变为未发布。
- **撤回**：撤销当前待审核操作，恢复提交前状态和可编辑能力。
- **删除**：仅未发布且没有待审核操作时可用；删除知识库不删除其引用的数据源。

### 5. 已发布配置变更

- 已发布知识库修改名称或描述，可按现有保存规则更新，不改变数据源引用关系。
- 新增、移除或替换数据源会改变检索内容，保存前必须二次确认；确认后知识库返回未发布状态，需要重新提交发布审核。
- 变更可见范围同样视为影响使用范围的关键变更，需重新发布。

### 6. 发布完整校验

提交发布前必须满足：

- 基本信息必填项完整；
- 至少引用 1 个已启用数据源；
- 引用上传数据源时，该数据源至少存在 1 个解析成功文档；
- 引用 API 或 MCP 数据源时，最近一次连接测试成功；
- 专家或岗位知识库已选择有效的可见对象。

校验失败时保留当前编辑内容，在对应字段处展示具体原因，不进入审核中。

### 7. 检索测试

- 已发布的知识库可点击【检索测试】，测试不会修改或发布知识库。
- 弹窗标题为「检索测试 · [知识库名]」。
- 弹窗字段：

| 字段 | 规则 |
|---|---|
| 检索问题 | 文本输入，默认填充示例值"公司的标准解决方案包括哪些内容？"。 |
| Top K | 下拉选择，选项按数值升序排列为 3、5、10、20，默认选中 5。 |
| 数据源范围 | 下拉选择，默认且仅展示"全部已启用数据源"。 |

- 点击【开始测试】后展示结果总数、耗时和各数据源召回统计。
- 结果卡片展示排名、相关度分数、数据源类型、来源名称、页码/定位信息和命中内容；长内容默认收起，可展开查看。
- 某一数据源失败时展示该来源错误，但仍展示其他数据源的正常结果。
- 未输入问题时【开始测试】置灰不可点（按钮禁用本身即为引导，不再另设空状态页）；知识库没有可用数据源时提示先配置并启用数据源。

### 8. 跨模块入口

岗位知识库支持从两个入口访问，其中仅知识库管理列表可创建：

- **知识库管理列表**：在知识库管理列表中【新建知识库】时，可选择类型为"岗位知识库"并选择可见范围岗位。
- **岗位详情页"知识"页签**：从岗位详情页的"知识"页签可查看和检索测试已关联的岗位知识库。

从岗位详情页"知识"页签的列表中，可对岗位知识库执行以下跨模块操作：

- 点击【查看】跳转至知识库模块并打开知识库查看抽屉。
- 点击【检索测试】在当前页面直接打开检索测试弹窗，不跳转模块；平台各入口打开的检索测试弹窗为同一个独立弹窗。

> 从岗位详情页跳转至知识库模块时，知识库列表筛选自动清空，展示全部知识库。

专家编辑抽屉的"知识库"区同样可访问知识库，仅展示类型为"专家知识库"且可见范围包含该专家的记录，行内提供【查看】【检索测试】，不提供新建与编辑入口（详见《prd.专家.md》§三.5）。

## 四、数据源管理

### 1. 列表筛选与入口

| 筛选项 | 规则 |
|---|---|
| 关键词 | 按数据源名称模糊查询。 |
| 数据源类型 | 全部、上传、API、MCP。 |
| 状态 | 全部状态、启用、停用。 |

- 点击【查询】执行筛选；筛选变化后从第 1 页展示。页面右上角展示【新建数据源】。
- 新建时先选择数据源类型，保存后类型不可修改。

### 2. 列表字段

| 字段 | 展示规则 |
|---|---|
| 数据源名称 | 展示名称，点击进入配置。 |
| 类型 | 上传、API 或 MCP。 |
| 概要 | 上传展示文档总数与解析情况（如"86 篇文档"）；API/MCP 展示"已连通"、"连接失败"或"未验证"（新建保存后、未测试前显示）；连接失败时使用警告样式。 |
| 状态 | 启用、停用。停用数据源不会参与知识检索。 |
| 被引用 | 展示被引用的知识库名称列表；无引用显示"—"。 |
| 操作 | 【查看】【编辑】为固定操作；上传数据源额外展示【文档管理】；未被知识库引用时展示【删除】，被引用时【删除】置灰并提示"正被知识库引用，请先解除引用"。 |

- 被知识库引用的数据源不可删除；【删除】置灰并提示"正被知识库引用，请先解除引用"。
- 删除未被引用的数据源需二次确认。上传数据源删除时，同时删除其文档和索引数据。

### 3. 数据源公共字段

| 字段 | 必填 | 规则 |
|---|---:|---|
| 数据源名称 | 是 | 最多 50 个字符。 |
| 类型 | 是 | 上传、API、MCP；创建后不可修改。 |
| 状态 | 否 | 启用或停用；停用后跳过检索，但保留配置和引用。 |

- 数据源保存后立即生效，不经过知识库发布审核；知识库是否向使用方开放仍由知识库自身状态控制。
- API 和 MCP 数据源修改连接配置后需要重新测试，编辑界面展示"修改连接配置后需要重新测试"提示。
- 密钥、Token 等敏感信息保存后遮罩展示，不在列表、日志或错误信息中回显明文。

## 五、上传数据源

### 1. 配置字段

| 字段 | 规则 |
|---|---|
| 文档类型 | 文档、表格、FAQ。 |
| 预处理 | 系统默认删除目录、页眉页脚、水印。可选处理：替换连续空格/换行符/制表符、提取 URL 和邮箱地址（默认开启）、纯文本化表格内容。 |
| Embedding 模型 | 选择平台可用的 Embedding 模型（如 text-embedding-3-small、bge-m3）。 |
| 检索策略 | 混合检索、向量检索、关键词检索。 |
| Top-K | 1～20，默认 5。 |

- 检索阈值不在管理端设置，由客户端每次发起检索时提供。
- 修改 Embedding 模型会影响现有索引，保存前提示"更换后需全量重建索引"；确认后重新处理已有文档。
- 处理选项根据文档类型动态展示，不展示对当前类型无效的配置。

### 2. 文件支持

| 文档类型 | 支持格式 |
|---|---|
| 文档 | PDF、DOCX、DOC、MD、TXT、HTML。 |
| 表格 | XLSX、XLS、CSV。 |
| FAQ | XLSX、CSV，需符合 FAQ 模板字段。 |

- 单文件最大 50MB。
- 格式或大小不符合要求时在上传前拦截，并说明支持范围。

### 3. 文档管理抽屉

- 支持一次选择多个文件上传。
- 列表展示文件名、大小、切片数、解析状态、失败原因和操作。
- 解析状态包括：等待解析、解析中、解析成功、解析失败。
- 存在解析中任务时，每 3 秒自动刷新状态；全部结束后停止轮询。
- 删除文档前二次确认；确认后删除文件、切片和索引内容。
- 顶部汇总文档总数和解析成功数，便于判断是否满足发布条件。

## 六、API 数据源

### 1. 连接配置

| 字段 | 必填 | 规则 |
|---|---:|---|
| 请求地址 | 是 | 最多 500 个字符，需为合法 HTTP/HTTPS 地址。 |
| 请求方法 | 是 | POST、GET、PUT、DELETE、PATCH，默认 POST。 |
| 鉴权方式 | 是 | 无鉴权、API KEY、Bearer Token，默认 API KEY。 |
| 超时时间 | 是 | 1000～60000ms，默认 8000ms。 |

#### 1.1 鉴权方式说明

- 选择”无鉴权”时不展示凭证字段。
- 凭证会静态附加到每次请求。

**API KEY 模式**：以多参数表格形式配置，每行包含以下字段：

| 列 | 必填 | 规则 |
|---|---:|---|
| 参数名 | 是 | 如 `X-Api-Key`。 |
| 描述 | 否 | 参数用途说明，标注”客户端可见”。 |
| 客户端填写 | 否 | 勾选后该参数由客户端用户在使用时填写，平台值输入框禁用。 |
| 位置 | 是 | Query、Body、Header、Path 之一。 |
| 参数值 | 条件必填 | 未勾选”客户端填写”时必填；按敏感信息处理，以密码形式输入，保存后遮罩。 |

- 点击【添加参数】新增一行；点击行尾【删除】移除该行。
- 至少保留一行有效参数。

**Bearer Token 模式**：展示 `Authorization: Bearer` 前缀提示和一个密码输入框。

| 字段 | 必填 | 规则 |
|---|---:|---|
| Bearer Token | 是 | 不含 `Bearer` 前缀；以密码形式输入，保存后遮罩。 |

### 2. 请求参数映射

请求参数映射用于定义平台向 API 发送请求时的参数结构。以表格形式配置，每行包含以下字段：

| 列 | 规则 |
|---|---|
| API 参数名 | 发送给 API 的实际参数名称。 |
| 类型 | string、number、integer、boolean、object、array。 |
| 必填 | 勾选表示该参数为必传。 |
| 映射客户端字段 | 指定该参数对应的平台客户端字段（如检索词、topK 等）。 |
| 默认值 | 未映射客户端字段或客户端未传值时使用的默认值。 |

- 预设两行固定参数：`query`（映射客户端检索词，必填）和 `topK`（映射客户端 Top K）。固定参数不可删除。
- 点击【添加参数】新增自定义参数行；点击行尾【删除】移除自定义参数。
- 类型选择 object 或 array 时，在当前字段下展开子字段区域；新增的子字段若继续选择 object 或 array，仍可展开自己的下一层子字段，递归支持多层嵌套。
- 新建 API 数据源默认展示一组可编辑、可删除的三级结构示例：filters（API 参数，object）→ rules（子字段，array）→ field / value（子字段的子字段），另在 filters 下与 rules 同级展示一个 enabled（boolean）子字段，用于直观说明递归配置方式；示例字段不属于平台强制参数。
- 子字段行展示：子字段名、类型、默认值和删除操作；每个 object / array 层级均显示“object / array 可继续嵌套”提示，并在底部提供【添加下一级子字段】。
- 使用缩进、左侧层级线和不同层级背景色表达父子关系；展开中的 object / array 类型选择框使用强调色标识。
- 子字段名必填，同一父字段下不可重名；object / array 保存时至少包含一个有效子字段。
- 删除父字段或任一中间字段时，同时删除其下全部后代字段。
- 将 object / array 切换为基础类型时收起子字段区域并暂存当前子字段草稿；切回 object / array 时恢复。最终保存为基础类型时不提交已收起的子字段。

### 3. 响应字段映射

响应字段映射用于定义 API 返回结果中各字段的解析规则。以表格形式配置，每行包含以下字段：

| 列 | 规则 |
|---|---|
| 参数名 | API 返回的字段名称。 |
| 描述 | 字段用途说明。 |
| 变量类型 | string、number、integer、boolean、object、array。 |

- 预设三行字段：`content`（内容，string）、`source`（来源，string）、`score`（相关度分数，number）。预设字段不可删除，变量类型可修改。
- 点击【添加字段】新增自定义字段行；点击行尾【删除】移除自定义字段。
- 保存时至少保留一条输出字段，全部删除时阻断保存。
- 检索返回时遍历下游结果数组，仅保留已配置的字段，其余字段一律过滤；字段值与嵌套结构沿用 API 返回原样，不做改名映射。
- 映射无效或返回内容不可解析时，测试结果中展示具体字段错误，不保存为”验证成功”。

### 4. 连接测试

- 点击【测试连接】使用当前表单配置发起一次受控测试。
- 测试校验网络可达、鉴权、响应状态、JSON 格式和字段映射。
- 成功后记录最近验证结果与时间；修改请求地址、鉴权或映射后，验证状态重置为未验证。
- 失败时展示可理解的错误原因和错误码，不展示敏感凭证。

## 七、MCP 数据源

### 1. 接入方式

支持**直接填写**：在数据源内直接配置 MCP 服务连接信息。

### 2. 直接填写 — 传输方式

直接填写时需选择传输方式：streamable-http 或 stdio。

#### 2.1 streamable-http

| 字段 | 必填 | 规则 |
|---|---:|---|
| Endpoint | 是 | MCP 服务地址，最多 500 个字符，需以 http:// 或 https:// 开头。 |
| 鉴权方式 | 是 | 无鉴权、Bearer Token、API Key，默认无鉴权。 |

- 选择”无鉴权”时不展示凭证字段。

**Bearer Token 模式**：

| 字段 | 必填 | 规则 |
|---|---:|---|
| Bearer Token | 是 | 不含 `Bearer` 前缀；以密码形式输入，保存后遮罩。 |

**API Key 模式**：

| 字段 | 必填 | 规则 |
|---|---:|---|
| Header 名 | 是 | 最多 128 个字符，仅允许字母、数字和连字符；如 `X-Api-Key`。 |
| 访问凭证 | 是 | 以密码形式输入，保存后遮罩。 |

#### 2.2 stdio

| 字段 | 必填 | 规则 |
|---|---:|---|
| Command | 是 | 下拉选择：npx、uvx、node、python3、docker。 |
| Arguments | 否 | 多行输入，每行一个参数。 |

**环境变量表**：以表格形式配置，每行包含以下字段：

| 列 | 必填 | 规则 |
|---|---:|---|
| 变量名 | 是 | 环境变量名称。 |
| 描述 | 否 | 变量用途说明，标注”客户端可见”。 |
| 客户端填写 | 否 | 勾选后该变量由客户端用户在使用时填写，平台值输入框禁用。 |
| 平台值 | 条件必填 | 未勾选”客户端填写”时必填；按敏感信息处理，保存后遮罩。 |

- 点击【添加变量】新增一行；点击行尾【删除】移除该行。

### 3. 检索工具

- 检索工具以多选复选框形式展示，列出 MCP 服务提供的可用工具（如 `search_documents`、`search_chunks`、`hybrid_search` 等）。
- 至少选择一个工具用于知识检索。
- 直接填写时需先完成连接测试以获取工具列表。

### 4. 超时时间

- 必填，取值范围 1000～120000ms，默认 10000ms；使用系统默认值并允许用户直接修改，不采用”留空跟随全局”。

### 5. 连接测试

- 测试需覆盖服务可达、鉴权有效、工具存在。
- 成功后记录最近验证时间；修改服务地址、鉴权或工具后重置为未验证。
- 失败时展示错误原因和错误码，凭证内容必须脱敏。

## 八、状态与异常规则

### 1. 状态定义

- 知识库列表状态：未发布、审核中、已发布。
- 待发布和待停用通过“待审核操作”区分，列表统一展示审核中；撤回后恢复提交前状态。
- 数据源状态：启用、停用。
- API/MCP 验证状态：连接正常、连接失败、未验证（新建保存后未测试前显示"未验证"）；验证状态不替代启用状态。数据源列表概要按验证状态展示：新建保存后未测试为"未验证"；连接测试通过后为"已连通"（MCP 附所选检索工具名，如"已连通 · search_documents"）；测试失败为"连接失败"；修改连接配置后重置为"未验证"。

### 2. 通用异常

- **列表加载失败**：保留查询条件，展示原因和【重试】。
- **保存失败**：保留表单内容，不关闭抽屉，不更新状态。
- **重复提交**：请求进行中禁用相关按钮。
- **权限变化**：提示权限不足，停止当前操作并刷新可用操作。
- **数据已变化**：提交时发现服务端版本变化，提示刷新后重新编辑，避免静默覆盖。
- **敏感信息**：错误信息、测试记录和页面日志均不得回显完整密钥或 Token。
