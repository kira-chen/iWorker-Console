## 1. 岗位直接引用技能，取消 Agent（R1）

涉及：岗位详情「技能」页签、岗位列表、岗位发布校验、岗位查看抽屉、技能强制回收说明、工具调用审计。

**取消 Agent**
- 岗位下不再有 Agent 这一层，技能直接引用到岗位。
- 岗位详情页签「Agent 与技能」改名「技能」。
- 新建、编辑、删除 Agent 的入口、抽屉和提示一并删除。

**「技能」页签**
- 列表：单层表格，一行一个技能，展示技能名称、技能分类、工具数量，行内【编辑】【移除】。【编辑】进入技能编辑页，编辑完成后可以【← 返回】回到岗位详情页的「技能」页签。
- 添加：页签右上角【添加技能】，打开技能选择抽屉，标题"添加技能"。
- 候选范围：已发布、未回收的岗位私有技能，排除本岗位已经引用的。"已发布"按技能本身的状态判断，有新版本或停用在审核中的仍算已发布（同修改点 4）。同一个技能可以被多个岗位引用；同一岗位内同一技能只引用一次。是否允许岗位直接引用市场技能、通用技能【待确认】。
- 上限：每个岗位最多引用 100 个技能，已引用的加上本次勾选的合计不超过 100。抽屉内展示"已勾选 N · 已引用 M / 上限 100"，达到上限后未勾选的复选框置灰，抽屉内显示提示"每个岗位最多引用 100 个技能"；已引用满 100 个时，【添加技能】置灰并显示"已达 100 个上限"，悬停提示同上。
- 移除：弹出确认"仅解除技能与当前岗位的关联，不删除技能本身。确认移除？"，确认后提示"技能已移除"。本岗位有自动化任务在「引用技能」里引用着这个技能时不能移除：点【移除】后直接提示"「技能名」正被自动化任务「任务名」引用，请先从任务里移除"，不弹确认；被多个任务引用时任务名依次列出，如"自动化任务「任务A」「任务B」"。【待确认】
- 强制回收：技能被强制回收后，岗位对它的引用保留，名称旁加红色"已回收"标签，悬停展示回收原因、操作人和时间；由管理员手动移除，发布前检查阻断。
- 空状态："暂无技能 · 点「添加技能」引用岗位私有技能"。

**岗位发布校验**
- 阻断项第 8 条由"Agent 与技能：至少配置 1 个 Agent，且该 Agent 至少引用 1 个技能"改为"技能：至少引用 1 个技能"；校验失败时定位到「技能」页签。
- 发布前检查弹窗中"Agent 与技能：存在 X 个工具未验证"改为"技能：存在 X 个工具未验证"。
- "引用已回收对象"动态阻断项的说明里，"Agent 技能子行"改为"技能页签"。

**其他页面**
- 岗位列表：删除「Agent 数」列，「技能数」口径不变。
- 岗位 SOP 占位改为"说明岗位如何组合使用技能、知识与工具完成工作"。
- 岗位查看抽屉（审核中心、我的申请里的岗位详情也用它）：技能区改为平铺展示，不再按 Agent 分组。
- 技能强制回收说明中"岗位 Agent 的技能子行"改为"岗位「技能」页签"。
- 工具调用审计中"所引用技能 / Agent 声明的工具"去掉"Agent"。
- 自动化任务「提示词」的说明"定时触发时，Agent 读取该内容作为任务指令执行业务。"改为"定时触发时，数字员工读取该内容作为任务指令执行业务。"

**存量数据**
- 存量岗位里各 Agent 下的技能，合并成岗位的技能列表，合并后不会重复。
- Agent 名称和职责描述不保留。需要留下的分工说明，由管理员写进岗位 SOP。【待确认】
- 合并后超过 100 个技能的岗位保留全部技能，降到 100 个以内之前不能再添加。

**客户端**
- 岗位技能随岗位下发，主实例直接调用，不再有 Agent 委派。下发结构，以及已领用实例里的 Agent 怎么转换【待研发确认】。

## 5. 采集字段 key 按完整拼音生成（R10）

涉及：岗位详情「采集字段」页签。

- 输入字段名后，字段 key 输入框的占位实时展示生成的建议值；保存时 key 为空则使用建议值。
- 生成规则：
  1. 汉字转为不带声调的全拼，字与字之间直接连写；多音字取常用读音。
  2. 英文字母转小写，数字原样保留。
  3. 空格、连字符转为下划线，其他符号去掉。
  4. 结果以数字开头时加前缀 `f_`；结果为空时使用 `field`。

## 20. 点踩对话明细展示助手回复里生成的文件（R16）

涉及：驾驶舱「使用情况」页签的点踩明细弹窗、对话明细弹窗（驾驶舱 PRD 第八、九节）。反馈场景：只看聊天文字判断不了用户为什么点踩，回复里生成的文件看不到。

- **留存范围**：用户点踩时，被点踩回复里生成的文件随这一轮一起留存（客户端本地对话同样回传这一轮的文件）。用户提问里上传的附件不留、不展示。留存期限、单个文件大小上限【待研发确认】。

- **对话明细**：被点踩的回复气泡下方逐个展示文件卡片：
