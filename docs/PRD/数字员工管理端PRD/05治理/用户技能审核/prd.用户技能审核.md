# 用户技能审核产品需求

## 一、产品目标与入口

用户技能审核面向审核管理员，用于核查用户端上传技能时被安全检测拦截的记录。

- **页面入口**：侧边栏"05 治理 / 用户技能审核"。
- **页面说明**：审核用户上传的自定义技能，处理高风险检测记录，并设置风险尺度。
- 需要用户技能审核权限；无权限时不展示入口和审核操作。
- 本模块与"审核中心"分开：审核中心处理平台业务对象的发布、版本发布和停用申请；用户技能审核只处理用户端技能安全检测产生的人工审核记录。

---

## 二、用户端检测与流转

### 2.1 安全检测项

用户端上传或安装技能时，对以下 4 个检测项执行检测，界面必须完整展示 4 项结果，未命中风险的项目也要展示"检测通过"。

| 检测项 | 说明 |
| --- | --- |
| 对外动作 | 技能中包含向外部系统发送请求或传输数据的操作 |
| 敏感信息 | 代码或配置中存在明文密码、API Key、Token 等敏感凭证 |
| 权限范围 | 申请的权限超出业务场景所需的最小权限范围 |
| 危险操作 | 包含可能造成不可逆影响的操作，如批量删除、全量更新等 |

> 注：检测项内部标识为"敏感信息明文凭证"，页面展示名称为"敏感信息"。

### 2.2 检测结果等级

每个检测项只能返回以下一种结果：

| 结果   | 颜色标记 | 说明         |
| ---- | ---- | ---------- |
| 检测通过 | 绿色   | 未发现该类风险    |
| 低风险  | 中性灰  | 轻微风险       |
| 中风险  | 橙黄色  | 存在需关注的风险   |
| 高风险  | 红色   | 存在严重风险     |
| 严重风险 | 深红色  | 致命性漏洞或严重违规 |

### 2.3 人工审核触发条件

系统根据当前审查尺度（宽松 / 通用 / 严格）以及各检测项配置的"触发审核的最低风险等级"判断是否触发人工审核。若任意检测项的检测结果严重程度 ≥ 该项配置的最低风险等级，则触发人工审核；若该项配置为"不进入审核"，则该项不触发人工审核。

## 三、查询区

查询区从左到右展示：

1. **搜索框**：占位"搜索技能名称 / 描述 / 提交人"，支持技能名称、技能描述、提交人用户名模糊搜索。
2. **审核尺度**：全部审核尺度、宽松、通用、严格。选择后即时刷新列表。
3. **审核状态**：全部审核状态、待审核、已通过、已驳回。选择后即时刷新列表。（全站审核状态词统一口径：待审核 / 已通过 / 已驳回，不使用「待审批」等其他写法。）
4. **查询按钮**：按当前条件刷新列表；搜索框按 Enter 同样触发查询。

查询条件可组合使用。

## 四、审核列表

### 4.1 展示字段

| 字段   | 展示规则                                          |
| ---- | --------------------------------------------- |
| 技能名称 | 展示用户提交审核的技能名称                                 |
| 描述   | 展示技能用途描述，超长省略，悬停查看完整内容                        |
| 提交人  | 展示用户端提交人的用户名                                  |
| 提交时间 | 精确到分钟，列头点击可切换正序 / 倒序（默认倒序），以 ↑ / ↓ 图标指示当前排序方向 |
| 审核状态 | 待审核（黄色）、已通过（绿色）、已驳回（红色）                       |
| 审核尺度 | 宽松（绿色）、通用（蓝色）、严格（红色）                          |
| 操作   | 所有状态展示【查看技能】；待审核额外展示【通过】【驳回】                  |

列表根据页面高度动态分页。可通过状态筛选查看已完成的历史审核记录。右上角提供【风险设置】按钮。

## 五、查看技能与检测明细

点击【查看技能】打开右侧详情抽屉，抽屉标题为"查看技能"，底部固定展示【关闭】按钮（待审核记录额外展示【通过】【驳回】）。详情使用提交审核时生成的只读快照，审核过程中不可编辑。

### 5.1 基本信息

| 字段 | 展示规则 |
| --- | --- |
| 技能名称 | 提交审核时的技能名称 |
| 提交人 | 用户端提交人的用户名 |
| 提交时间 | 记录进入审核队列的时间，精确到分钟 |
| 审核状态 | 待审核、已通过或已驳回 |
| 审核尺度 | 执行用户端安全检测时采用的尺度 |
| 技能描述 | 提交审核时的技能描述 |

### 5.2 SKILL.MD

展示提交时技能包中 SKILL.MD 的原始内容，只读，内容原样呈现不做渲染。内容为空时展示"（暂无内容）"。

### 5.3 检测明细

检测明细标题区展示"共 4 项"，依次展示：

1. 对外动作
2. 敏感信息
3. 权限范围
4. 危险操作

每个检测项展示：

- 检测项序号和名称。
- 检测结果标签（颜色参见 2.2）。
- 命中位置（如有）。
- 命中代码片段（如有，以等宽字体代码块展示）。
- 检测依据或命中详情；检测通过时展示"未检测到该项相关风险"。

## 六、审核操作

### 6.1 通过

列表行【通过】或详情底部【通过】均弹出确认弹窗。

- 弹窗标题为"通过审核"，确认按钮为"确认通过"。
- 弹窗说明：确认通过「技能名称」的审核申请，通过后提交人将可立即使用此技能。
- 确认后记录审核人和审核时间，审核状态更新为"已通过"，并弹出"审核已通过"提示。

### 6.2 驳回

列表行【驳回】或详情底部【驳回】均弹出"驳回审核"弹窗。

- 弹窗说明文：请填写驳回原因，驳回后提交人将收到通知并需修改后重新提交。
- **驳回原因**为必填文本域，最多 500 字，占位提示"请输入驳回原因（必填）"；为空时阻止提交，输入框标红并聚焦，弹出"请填写驳回原因"提示。
- 确认按钮为"确认驳回"。
- 列表行【驳回】使用红色文字链接样式，详情底部【驳回】使用红色底色主按钮样式。
- 确认后记录审核人、审核时间和驳回原因，审核状态更新为"已驳回"，并弹出"审核已驳回"提示。

### 6.3 已完成记录

- 已通过和已驳回记录只展示【查看技能】，不展示审核操作按钮。
- 审核结果不可直接二次修改；确需重新处理时，由用户端基于新版本重新提交。

## 七、风险设置

点击列表右上角【风险设置】打开右侧抽屉，分两个区域，抽屉顶部说明文为"维护三套审核尺度模板，管控技能上传的安全检测策略。"。

### 7.1 当前审查尺度

展示单选按钮，选项顺序为：通用、严格、宽松，默认选中"通用"。选择后暂存为未保存改动，点击【保存设置】后生效，影响触发人工审核的判断逻辑。

### 7.2 审核尺度模板配置

维护宽松、通用、严格三套审核尺度模板。通过 Tab 切换编辑，每套尺度独立保存。默认打开"通用"Tab。

Tab 下方展示当前尺度的适用说明：

- **宽松**：四项检测均不进入人工审核，检测结果仅作记录，适合内部可信来源的技能。
- **通用**：默认策略，敏感信息达到严重风险、其余三项达到高风险时进入人工审核。
- **严格**：在通用基础上收紧，对外动作、权限范围和危险操作降到中风险即进入人工审核，适合对外发布场景。

配置表格列：检测项 | 说明 | 触发审核的最低风险等级

各检测项可选的"触发审核的最低风险等级"选项如下：

| 检测项            | 可选等级                   |
| -------------- | ---------------------- |
| 对外动作           | 严重风险、高风险、中风险、不进入审核     |
| 敏感信息           | 严重风险、高风险、不进入审核         |
| 权限范围           | 高风险、中风险、低风险，不进入审核      |
| 危险操作           | 严重风险、高风险、中风险、低风险、不进入审核 |

各套尺度的默认值：

| 审核尺度 | 对外动作  | 敏感信息  | 权限范围  | 危险操作  |
| ---- | ----- | ----- | ----- | ----- |
| 宽松   | 不进入审核 | 不进入审核 | 不进入审核 | 不进入审核 |
| 通用   | 高风险   | 严重风险  | 高风险   | 高风险   |
| 严格   | 中风险   | 严重风险  | 中风险   | 中风险   |

抽屉底部按钮：

- 【恢复默认】：将当前 Tab 的配置恢复为上表默认值，并弹出"已恢复默认设置"提示。
- 【取消】：关闭抽屉，**清空当前未保存的内容**（当前审查尺度与模板配置的改动一律不生效，下次打开回到已保存状态）。
- 【保存设置】：保存当前 Tab 的模板配置与「当前审查尺度」选择，弹出"「尺度名」审核尺度设置已保存"提示并关闭抽屉。**只有保存才视为生效。**

## 八、异常与空状态

| 场景 | 处理 |
| --- | --- |
| 列表为空 | 展示空态文案"没有符合条件的审核记录" |
| 加载失败 | 展示错误原因，并提供【重试】按钮 |
| 无权限 | 不展示页面入口和审核操作 |
