# 工具调用审计产品需求

> **来源说明**：本模块此前仅存在于已退场的旧交互原型（`数字员工管理端交互原型.html` · 05 治理 / 工具调用审计）中，PRD 正本此前未收录该模块。本篇基于原型的交互内容改写为产品文字稿，作为该模块 PRD 正本的首次落地；原型本身自 2026-09-09/10 起已不再作为对齐依据，此处仅补充需求来源，不代表原型细节自动生效——本篇文字稿与访问审计、实例管理等既有模块的表述如有出入，以本篇及后续修订为准。

## 一、产品目标与入口

工具调用审计用于记录和查看数字员工在执行技能、岗位自动化任务以及知识库检索过程中，调用外部工具（MCP / API / 业务系统连接器）或第三方知识服务的完整过程，包括发起人、是否需要确认或授权、执行结果，供管理员事后审计与追溯。

- **页面入口**：侧边栏"05 治理 / 工具调用审计"。
- **页面标题**：工具调用审计。
- **页面说明**：追溯每次工具调用的发起人、确认过程与执行结果。
- 页面只读，不提供修改或删除操作（与访问审计一致）。

### 页签结构

页面顶部展示三个页签，页签与内容区之间有分隔线（与连接器页面、访问审计一致）：

| 页签 | 记录什么 | 触发方式 | 确认 / 授权 |
| --- | --- | --- | --- |
| 技能调用 | 用户在对话中触发，技能调用 MCP / API / 业务系统连接器 | 用户发起，有人在场 | 写操作需用户确认 |
| 岗位自动化任务 | 岗位自动化任务按调度计划触发（周期 / 每间隔 / 单次 / 闲时），通过任务的"引用工具"或所引用的技能 / Agent 调用连接器 | 调度触发，无人值守 | 无用户确认；写操作需在任务中预授权（见 §八.2） |
| 知识库检索 | 用户提问时，岗位 / 专家引用的知识库经 API / MCP 数据源向第三方知识服务发出的检索 | 用户提问触发 | 只读，不需确认 |

- 默认进入"技能调用"页签；切换页签时各页签的查询条件、分页、排序状态相互独立，互不影响。
- 三个页签的统计卡片、列、详情各不相同：**§二 ~ §七 描述"技能调用"页签**，其中 §三 时间范围规则、§六 标签颜色、§七 异常与空状态对另两个页签同样适用；"岗位自动化任务""知识库检索"两个页签只在 §八、§九 写明与它的差异。

### 模块边界

- 本模块只记录**已发生的工具调用事件**，供事后审计追溯，不提供实时任务队列、运行实例健康度、会话运行状态等运维视图。该边界与 04运行/实例管理 2026-09-16 评审结论保持一致——该评审已明确"本期不再建设会话运行监控"，任务处置、会话汇总等运维职责不在本模块范围，也不在实例管理范围内。
- 本页面不提供工具白名单、确认策略等规则的配置入口；一次调用是否需要用户确认、是否命中白名单拦截，由连接器 / 技能 / 岗位相关配置决定，本页仅呈现调用发生时的实际结果。该类配置能力目前尚未在其余模块 PRD 中定义，不在本次改造范围内，记入 `docs/04-待补需求定义/`；岗位自动化任务的写操作预授权同属此类（见 §八.2）。
- 本页只记录**经平台连接器 / 知识库数据源、由数字员工发起**的调用。用户绕开数字员工、直接在外部系统内的操作不经过平台，不在本页，以对应外部系统自身的日志为准。
- 管理员在管理端的"测试连接""拉取工具""检索测试"属于管理操作，不在本页；知识库的上传型数据源由平台自身检索，不是外部调用，也不在本页。

## 二、统计卡片

页面顶部展示 4 个统计卡片，点击卡片按下方 §三 的筛选条件快速筛选列表（不弹窗、不跳转）：

| 卡片 | 说明 | 点击效果 |
| --- | --- | --- |
| 调用请求总数 | 当前筛选范围内的全部调用请求数，副标题展示"成功 X / 拦截 X / 取消 X" | 清空执行结果、操作性质筛选，仅保留时间范围 |
| 写操作请求 | 操作性质为"写"的请求数，副标题展示"需要确认 X / 已确认 X" | 操作性质置为"写"，清空执行结果筛选 |
| 执行失败 | 已尝试执行但未成功的请求数 | 执行结果置为"执行失败" |
| 当前待确认 | 等待用户在客户端确认、尚未执行的请求数 | 执行结果置为"待确认" |

- 卡片下方提供【统计口径】说明入口，默认收起，展开后说明：
  - 调用请求包含成功、执行失败、执行前拦截、用户取消和待确认五类结果；一次任务内的重试按新的调用请求单独记录。
  - 执行耗时只统计工具实际执行时间，不含等待用户确认的时间。
  - "待确认"反映当前尚未处理的请求，不是历史累计数量。

## 三、查询区

查询区从左到右展示：

1. **时间范围**：日期区间选择器，规则与访问审计一致（默认展示当前日期向前 90 天，最多可选 30 天跨度，见访问审计 §三）。
2. **执行结果筛选**：下拉，全部结果 / 成功 / 执行失败 / 执行前拦截 / 用户取消 / 待确认；切换后立即刷新列表。
3. **操作性质筛选**：下拉，全部 / 读 / 写；切换后立即刷新列表。
4. **搜索框**：占位"搜索用户 / 岗位 / 技能 / 工具"，按用户名、岗位名、技能名或工具标识模糊搜索；输入后回车或点击【查询】生效。
5. **查询按钮**：按当前全部条件刷新列表并回到第 1 页。
6. **导出 CSV**（工具栏右侧）：导出当前筛选结果，展示"已导出 N 条筛选结果"。

时间范围、执行结果、操作性质、搜索框可以组合使用。

| 字段 | 展示规则 |

## 五、详情

点击【查看详情】从页面右侧打开详情抽屉，展示：

### 5.1 操作摘要

结果标签 + 用户 / 岗位、技能、工具标识、执行耗时 / 等待确认。

### 5.2 执行过程

时间线依次展示各阶段，被拦截 / 取消 / 待确认的调用在对应节点停止，不展示后续阶段：

1. **发起调用**：展示发起人与其通过的岗位、执行的技能。
2. **调用检查**：通过则进入下一阶段；未通过（执行前拦截）则展示拦截原因，时间线在此停止。
3. **用户确认**（仅"操作性质=写"且需要确认时展示）：已确认展示确认人与等待时长；待确认 / 已取消则时间线在此停止。
4. **执行结果**：展示最终结果、执行耗时，失败时附原因。

### 5.3 结果说明

一句话解释当前结果的含义与建议动作，例如：
- 执行失败：建议检查连接器状态及工具服务日志，并核对是否已有后续重试记录。
- 执行前拦截：请核对该岗位允许使用的工具和用户权限，再由发起人重新提交任务。
- 用户取消：本次操作已终止，如仍需执行请由发起人重新发起。
- 待确认：等待发起人在客户端处理，此页不代替用户确认。

### 5.4 请求参数 / 响应结果

两个页签，默认展示"实际请求参数"：

- **实际请求参数**：展示本次调用的请求参数，敏感字段（如联系方式、操作凭证）脱敏展示。
- **实际响应结果**：展示本次调用的响应内容；未执行的调用（执行前拦截 / 用户取消 / 待确认）展示"工具未执行，因此没有实际响应结果"。

关闭抽屉返回列表原有筛选条件与滚动位置。

## 八、岗位自动化任务页签

本节只写与"技能调用"页签（§二 ~ §七）的差异，未提及的规则（时间范围、排序、分页、导出、抽屉形态、标签颜色、异常与空状态）均与之相同。

### 8.1 记录范围与口径

- 记录岗位自动化任务（岗位 PRD"自动化任务"页签）按调度计划触发后，通过任务"引用工具"或所引用的平台技能 / Agent 调用 MCP / API / 业务系统连接器的每一次调用。用户在对话中触发的调用记在"技能调用"页签，不在此重复。
- 任务无人值守，没有实时用户：不存在"用户确认""待确认""用户取消"，执行结果只有**成功 / 执行失败 / 执行前拦截**三类。
- "用户 / 岗位"展示的是**任务所属用户**（领用该岗位的用户）及其岗位，不是调用发起人；发起方是调度计划，见"触发方式"列。
- 一次任务运行会连续调用多个工具，同一次运行内的调用共用同一个**任务运行编号**（格式 RUN-日期-任务标识），用于把它们串起来；运行内的重试按新的调用请求单独记录。

### 8.2 写操作授权（本期演示口径）

无人值守时，写类操作无法像"技能调用"那样当场请用户确认，本页按以下口径呈现：

- 任务保存时可对其引用的写类工具预先授权。已预授权的写操作直接执行，记为"已预授权"，详情展示授权人与授权时间。
- 未预授权的写操作在执行前被拦截，原因为"无人值守任务未授权写操作"，工具不执行。
- 读操作不需要授权，记为"不需要授权"。

> 该预授权的配置入口与规则，岗位 PRD 目前尚未定义；本页只呈现调用发生时的结果，待产品补充定义后再回填，记入 `docs/04-待补需求定义/`。

### 8.3 统计卡片

页面顶部展示 4 个统计卡片，点击卡片按 §8.4 的筛选条件快速筛选列表（不弹窗、不跳转）：

| 卡片 | 说明 | 点击效果 |
| --- | --- | --- |
| 调用请求总数 | 当前筛选范围内的全部调用请求数，副标题展示"成功 X / 拦截 X" | 清空执行结果、操作性质筛选，仅保留时间范围 |
| 写操作请求 | 操作性质为"写"的请求数，副标题展示"已预授权 X / 未授权拦截 X" | 操作性质置为"写"，清空执行结果筛选 |
| 执行失败 | 已尝试执行但未成功的请求数 | 执行结果置为"执行失败" |
| 执行前拦截 | 未进入工具执行阶段、被拦截的请求数 | 执行结果置为"执行前拦截" |

卡片下方【统计口径】入口，默认收起，展开后说明：调用请求包含成功、执行失败、执行前拦截三类结果，任务无人值守故不存在用户取消和待确认；写操作需在任务中预授权；运行内的重试按新的调用请求单独记录，可用任务运行编号串联；执行耗时只统计工具实际执行时间。

### 8.4 查询区

从左到右：时间范围（同 §三）→ 执行结果筛选（全部结果 / 成功 / 执行失败 / 执行前拦截）→ 操作性质筛选（全部 / 读 / 写）→ 搜索框 → 查询按钮 → 导出 CSV（工具栏右侧）。

- 搜索框占位"搜索用户 / 岗位 / 任务 / 工具"，按用户名、岗位名、任务名、工具标识、请求编号或任务运行编号模糊搜索；输入后回车或点击【查询】生效。

| 任务 / 工具 | 触发本次调用的自动化任务名称，副标题展示工具标识（格式同 §四"连接器类型·连接器名称"） |

| 操作性质 | 读 / 写标签 |

| 执行耗时 | 工具实际执行耗时；未执行的调用展示"未执行" |
| 操作 | 固定展示【查看详情】按钮 |

### 8.6 详情

点击【查看详情】从右侧打开详情抽屉，结构同 §五：

- **操作摘要**：结果标签 + 用户 / 岗位、自动化任务、触发方式、任务运行编号、工具标识、执行耗时。
- **执行过程**依次展示，被拦截的调用在对应节点停止：①**任务触发**（按哪个调度计划触发了哪个任务、所属用户与岗位）；②**调用检查**（未通过则展示拦截原因，含未预授权的写操作，时间线在此停止）；③**写操作授权**（仅操作性质为"写"且已预授权时展示授权人与授权时间）；④**执行结果**。
- **结果说明**：执行失败——建议检查连接器状态及工具服务日志，并按任务运行编号核对同一次运行内是否已有后续重试记录；未授权的写操作被拦截——该任务未对写操作预授权，无人值守时不会自动执行，请在岗位自动化任务中核对工具授权，或改由用户在对话中发起；其他拦截——请核对该岗位允许使用的工具和任务所属用户权限，任务下次运行时会重新检查。
- **请求参数 / 响应结果**：同 §5.4。

## 九、知识库检索页签

本节只写与"技能调用"页签（§二 ~ §七）的差异，未提及的规则（时间范围、排序、分页、导出、抽屉形态、标签颜色、异常与空状态）均与之相同。

### 9.1 记录范围与口径

- 记录用户提问时，岗位 / 专家引用的知识库通过 **API 或 MCP 数据源**向第三方知识服务发出的检索请求（数据源口径见知识库 PRD §六、§七），每向一个数据源发出一次检索记一条。
- 上传型数据源由平台自身检索，不是外部调用，不在本页；管理端知识库的"检索测试"、数据源的"测试连接"属于管理操作，也不在本页。
- 检索只读、不需确认，执行结果只有**成功 / 执行失败 / 执行前拦截**（如用户无该知识库访问权限）。**检索成功但命中 0 条仍属"成功"**，靠"命中条数"区分，并在统计卡片单列"无命中检索"。
- 审计关心的是"检索词发给了哪个第三方知识服务、命中了哪些内容来源"，因此本页没有操作性质、用户确认两项。
- 检索词按用户提问原文记录并展示。检索词与命中内容是否需要脱敏、是否限制查看，目前产品尚未定义，页面标"【待补充】"，记入 `docs/04-待补需求定义/`。

### 9.3 查询区

从左到右：时间范围（同 §三）→ 执行结果筛选（全部结果 / 成功 / 执行失败 / 执行前拦截）→ 数据源类型筛选（全部 / API / MCP）→ 命中情况筛选（全部 / 有命中 / 无命中）→ 搜索框 → 查询按钮 → 导出 CSV（工具栏右侧）。

- 搜索框占位"搜索用户 / 岗位 / 知识库 / 检索词"，按用户名、岗位名、知识库名、数据源名、检索词或请求编号模糊搜索；输入后回车或点击【查询】生效。
- "有命中"指检索成功且命中不少于 1 条；"无命中"指检索成功但命中 0 条；失败和被拦截的检索不属于二者。

### 9.5 详情

点击【查看详情】从右侧打开详情抽屉，结构同 §五：

- **操作摘要**：结果标签 + 用户 / 岗位、知识库、数据源、检索工具（MCP 数据源展示所选检索工具，API 数据源展示"—"）、命中条数、执行耗时。
- **执行过程**依次展示，被拦截的检索在对应节点停止：①**发起检索**（谁通过哪个岗位提问，引用的知识库向哪个数据源发起检索）；②**调用检查**（未通过则展示拦截原因，时间线在此停止）；③**执行结果**（成功展示命中条数，失败附原因）。
- **结果说明**：执行失败——建议在知识库的"数据源管理"中重新测试该数据源的连接，并检查第三方知识服务状态；执行前拦截——请核对该用户所属岗位是否引用了该知识库，以及用户的知识库访问权限；无命中——检索成功但没有命中内容，可核对检索词与数据源内容是否匹配。
- **请求参数 / 响应结果**两个页签，默认展示"实际请求参数"：
  - **实际请求参数**：检索词（query）、返回条数上限（topK），MCP 数据源多一行检索工具（tool）。页签顶部提示"检索词按用户提问原文记录，脱敏口径【待补充】"。
  - **实际响应结果**：以列表展示命中的内容，列为"标题""来源名称"（对应数据源响应字段映射的 title / sourceName）；命中较多时展示前若干条，并说明"共命中 N 条，展示前 M 条"；命中 0 条展示"检索成功，命中 0 条"；未发出请求（执行前拦截）展示"检索未执行，因此没有实际响应结果"；失败展示失败原因，错误码及原始响应标"【待补充】"。
