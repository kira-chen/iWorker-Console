# 访问审计产品需求

## 一、产品目标与入口

访问审计用于记录和查看用户登录访问、用户端文件下载与管理端操作的完整行为轨迹，供管理员监控与追溯。

- **页面入口**：侧边栏"05 治理 / 访问审计"。
- **页面标题**：访问审计。
- **页面说明**：记录用户登录访问、用户端文件下载与管理端操作的完整行为轨迹。
- 页面只读，不提供修改或删除操作。

## 二、页签结构

页面顶部展示三个页签，页签与内容区之间有分隔线（与连接器页面一致）：

| 页签 | 说明 |
| --- | --- |
| 登录访问 | 用户登录、登出记录、终端、在线状态与来源 IP |
| 用户端文件下载 | 展示会话产物下载、知识库本地产物下载和知识库我的资料下载情况，含下载结果 |
| 管理端操作 | 管理员在管理端对各模块对象执行的变更操作记录 |

- 默认进入"登录访问"页签。
- 切换页签时各页签查询条件独立，互不影响。

## 三、时间范围筛选（三页签通用规则）

三个页签的查询区均提供时间范围选择器，规则统一如下：

- **默认范围**：保留所有天数记录，但页面仅展示当前日期向前 90 天（含当天），即今天减去 89 天至今天。
- **最大跨度限制**：用户最多可选 30 天的时间跨度。
  - 用户点选起始日期后，日期面板中距该日期超过 30 天（前后各 30 天）的日期自动置灰、不可点击；
  - 两端日期均选定后，置灰约束自动解除。
- **实时过滤**：调整时间范围后列表立即刷新，无需点击【查询】按钮。
- **独立状态**：各页签时间范围状态相互独立，切换页签不影响其他页签的已选区间。

## 四、登录访问

### 4.1 查询区

查询区从左到右展示：

1. **时间范围**：日期区间选择器，默认展示过去 90 天（见 §三），调整后列表立即刷新。
2. **搜索框**：占位"搜索用户名"，按用户名模糊搜索；输入后回车或点击【查询】生效。
3. **在线状态筛选**：下拉，全部在线状态 / 在线 / 离线；切换后立即刷新列表。
4. **查询按钮**：按当前全部条件刷新列表并回到第 1 页。

时间范围、搜索框、在线状态筛选可以组合使用。

### 4.2 列表展示

| 字段 | 展示规则 |
| --- | --- |
| 用户名 | 展示账号用户名 |
| 终端 | 仅展示 Windows、Mac 两类，均使用 accent 样式蓝色标签 |
| 登录时间 | 精确到分钟，支持正序 / 倒序切换，列头显示箭头"↓ / ↑" |
| 登出时间 | 在线记录显示"—"；离线记录显示实际时间，支持正序 / 倒序切换 |
| 状态 | 在线为绿色标签，离线为灰色标签 |
| 来源 IP | 展示本次登录来源 IP |

列表根据页面高度动态分页，默认按登录时间倒序展示。

### 4.3 数据规则

- 每条记录对应一次独立登录会话，不按用户名合并。
- 同一账号在不同终端、不同 IP 或不同时间登录时，系统分别记录多条日志。
- 终端枚举仅为 Windows、Mac。
- 当前在线记录的 `logoutAt` 为空；退出后补充登出时间并将状态更新为离线。
- 登录时间和登出时间分别保存，两个字段均可排序；按登出时间排序时，在线记录（无登出时间）统一排在列表末尾。
- 页面不展示登录地点，来源信息仅展示登录 IP。

## 五、用户端文件下载

### 5.1 查询区

查询区从左到右展示：

1. **时间范围**：日期区间选择器，默认展示过去 90 天（见 §三），调整后列表立即刷新。
2. **搜索框**：按文件名或用户显示名模糊搜索，占位"搜索文件名 / 用户名"。
3. **下载结果筛选**：下拉，全部结果 / 成功 / 失败；切换后立即刷新列表。
4. **产物来源筛选**：下拉，全部来源 / 会话产物 / 知识库·本地产物 / 知识库·我的资料；切换后立即刷新列表。
5. **查询按钮**：按当前全部条件刷新列表并回到第 1 页。
6. **导出 CSV**（工具栏右侧）：点击触发导出，展示"CSV 导出已开始，请稍候…"提示。

### 5.2 列表展示

| 字段 | 展示规则 |
| --- | --- |
| 下载时间 | 精确到分钟，支持正序 / 倒序切换，列头显示箭头"↓ / ↑" |
| 用户 | 展示用户显示名 |
| 产物文件名 | 展示下载的产物文件名，超长省略、悬停展示完整名称 |
| 终端 | 下载来源终端，仅展示 Windows、Mac 两类，使用 accent 样式蓝色标签 |
| 产物来源 | 会话产物 / 知识库·本地产物 / 知识库·我的资料，以灰色标签展示 |
| 下载结果 | 成功为绿色标签；失败为红色标签，同时展示具体原因：磁盘空间不足（CS端）/ 无写入权限（CS端）/ 保存失败（CS端）/ 下载失败（BS端）/ 未知异常（通用） |

列表根据页面高度动态分页，默认按下载时间倒序展示。

## 六、管理端操作

### 6.1 查询区

查询区从左到右展示：

1. **时间范围**：日期区间选择器，默认展示过去 90 天（见 §三），调整后列表立即刷新。
2. **搜索框**：按操作人用户名或操作对象名称模糊搜索，占位"搜索操作人 / 操作对象"。
3. **模块筛选**：下拉，按操作所属模块过滤，选项：岗位 / 专家 / 技能 / 知识库 / MCP / API / 业务系统 / 模型 / 审核中心 / 用户技能审核 / 版本管理；切换后立即刷新列表。
4. **动作筛选**：下拉，按操作类型过滤，选项：发布 / 停用 / 撤回 / 删除 / 审核通过 / 审核驳回；切换后立即刷新列表。
5. **查询按钮**：按当前全部条件刷新列表并回到第 1 页。
6. **导出 CSV**（工具栏右侧）：点击触发导出，展示"CSV 导出已开始，请稍候…"提示。

时间范围、搜索框、模块筛选、动作筛选可以组合使用。

### 6.2 列表展示

| 字段   | 展示规则                                                                         |
| ---- | ---------------------------------------------------------------------------- |
| 操作时间 | 精确到分钟，支持正序 / 倒序切换，列头显示箭头"↓ / ↑"                                              |
| 操作人  | 执行操作的管理员用户名                                                                  |
| 模块   | 操作所属模块，以彩色标签展示（颜色规则见 §6.4）                                                   |
| 动作   | 操作类型，以彩色标签展示（颜色规则见 §6.4）                                                     |
| 变更内容 | 仅两类操作记录说明文字：**审核驳回**时记录驳回原因；**版本发布**时记录升级说明（版本管理页发布客户端版本时，记录该版本的更新说明）；其余操作此字段为空，展示"—"。内容超长省略、悬停展示完整内容。 |
| 操作对象 | 被操作的对象名称。**仅岗位、专家、技能**三个模块的对象在名称右侧附版本号（灰色小标签，格式如"v1.4.2"）；其他模块不展示版本号小标签；**版本管理**模块的操作对象名称为"终端 + 版本号"（如"Windows v1.2.0"），版本号已在名称内，不再另附小标签。        |
| 操作   | 固定展示【查看】链接按钮，点击跳转至对应模块页（见 §6.3）                                              |

列表根据页面高度动态分页，默认按操作时间倒序展示。

> **版本管理记录**：管理员在版本管理页【发布】【停用】客户端版本成功后，各生成一条记录，动作分别为"发布""停用"（发布新版本引起的旧版本自动停用不单独记；删除仅限未上线的未发布版本，不记）。操作人为当前登录用户名，操作对象为"终端 + 版本号"，发布记录的"变更内容"为该版本的更新说明，停用记录为空。

### 6.3 查看操作

点击【查看】跳转至该记录对应的模块页面，并在搜索框中自动注入操作对象名称作为关键词，列表仅展示匹配该关键词的条目。

各模块跳转目标：

| 模块 | 跳转目标页 |
| --- | --- |
| 岗位 | 岗位列表页 |
| 专家 | 专家列表页 |
| 技能 | 技能列表页 |
| 知识库 | 知识库列表页 |
| MCP | 连接器页 · MCP 页签 |
| API | 连接器页 · API 页签 |
| 业务系统 | 连接器页 · 业务系统页签 |
| 模型 | 模型列表页 |
| 审核中心 | 审核中心页 |
| 用户技能审核 | 用户技能审核页 |
| 版本管理 | 版本管理页 |

若无对应模块权限，则暂不支持跳转，查看按钮置灰。

## 七、异常与空状态

| 场景 | 页面处理 |
| --- | --- |
| 查询无结果 | 展示空状态，保留搜索和筛选条件 |
| 日志加载失败 | 展示"加载失败"和【重试】 |
| 登出时间为空（登录访问） | 展示"—"，不视为异常 |
| 未识别终端 | 数据接入层映射为 Windows 或 Mac 后再展示 |
