# 各模块必填/选填字段一览表

> 依据各模块 PRD 整理。字数限制统一规则：**名称类字段最多 64 字符，描述类字段最多 2000 字符，示例类字段每条最多 300 字符**（例外：岗位 SOP 最多 4000 字符、SOP 简版最多 200 字符、自动化任务说明最多 500 字符、提示词最多 8000 字符、工作档案档案说明最多 500 字符、采集字段字段名最多 40 字符、业务页名称最多 20 字符、用户技能审核驳回原因最多 500 字符、扩容拒绝原因最多 500 字符，详见末尾「字数限制统一规则」）。版本管理有两处：客户端版本见「十二」，岗位、专家、技能提交新版本时的「升级说明」单列在末尾。
