# 知识库检索测试接口规范

## 接口说明

知识库检索测试接口用于对已发布的知识库进行检索验证，不修改、不发布知识库。

## 请求

### 接口路径
```
POST /api/knowledge-base/{id}/search
```

### 请求参数

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| query | string | 是 | 检索问题 |
| topK | number | 是 | 返回结果数量，可选值：3、5、10、20，默认 5 |
| sourceId | string | 否 | 数据源ID，不传则检索全部已启用数据源 |

### 请求示例
```json
{
  "query": "公司的标准解决方案包括哪些内容？",
  "topK": 5,
  "sourceId": "src_123"
}
```

## 响应

### 响应字段

| 字段名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| items | array | 是 | 检索结果列表 |
| errors | array | 是 | 错误列表（某数据源失败时） |
| elapsedMs | number | 是 | 检索耗时（毫秒） |

### items 结构

| 字段名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| rank | number | 是 | 排名序号（从1开始） |
| score | number | 是 | 相关度分数（0-1之间的浮点数） |
| sourceType | string | 是 | 数据源类型：UPLOAD（上传）/ API / MCP |
| sourceId | string | 是 | 数据源ID |
| sourceName | string | 是 | 数据源名称 |
| source | string | 是 | 来源文档名称 |
| page | number/null | 否 | 页码（上传类有页码，API/MCP为null） |
| content | string | 是 | 命中内容 |

### errors 结构

| 字段名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| sourceType | string | 是 | 数据源类型 |
| sourceId | string | 否 | 数据源ID |
| sourceName | string | 否 | 数据源名称 |
| message | string | 是 | 错误信息 |

## 业务规则

1. **数据源范围**：
   - 仅检索已启用（status=ENABLED）的数据源
   - 如果指定了 sourceId，则只检索该数据源
   - 已停用的数据源不参与检索

2. **失败处理**：
   - 单个数据源失败不影响其他数据源的检索结果
   - 失败的数据源信息记录在 errors 数组中
   - API/MCP 数据源连接失败（verifyStatus=FAILED）时会返回错误

3. **结果排序**：
   - 结果按 score 降序排列
   - rank 从 1 开始连续编号

4. **TopK 限制**：
   - 返回的结果数量不超过 topK 参数值
   - 如果实际召回数量少于 topK，返回实际数量

## 前端展示规范

### 统计信息
- 召回数量：`items.length` 条
- 检索耗时：`elapsedMs` ms
- 各数据源召回统计：按 sourceType 汇总显示

### 结果卡片
- 标题：`#${rank} ${source}`（加粗）
- 分数：`score.toFixed(2)`（绿色加粗）
- 数据源类型：标签展示（UPLOAD→上传 / API / MCP）
- 来源信息：`${sourceName} · 第 ${page} 页`（API/MCP无页码时省略）
- 内容：`content`（超过120字符默认收起，可展开）

### 错误展示
- 标题：数据源类型标签
- 内容：错误信息
- 提示：不影响其它数据源结果
