## 三、发现的差异点

### ❌ 差异 1：列表排序交互缺失 @sort-change 事件处理

**PRD 要求**（§4.1）：
> 点击列头"提交时间"可切换升降序

**代码现状**：
- `AdminPositionAssignments.vue` L416 存在 `@sort-change="onAppSortChange"`
- 但文件内**未定义 `onAppSortChange` 函数**
- 实际排序通过自定义按钮 `toggleAppSort` 实现 (L157-160)
- el-table 的 @sort-change 会因找不到处理函数而报错

**影响**：
- 点击 el-table 列头排序图标可能产生控制台错误
- 用户需点击自定义的"提交时间 ↓/↑"按钮才能排序（功能可用，但有冗余监听器）

**建议修复方案**：
```vue
<!-- 方案 1：移除 @sort-change，仅保留自定义按钮 -->
<el-table
  :data="appList.rows.value"
  class="pa-table"
>
  <!-- 移除 @sort-change 和 :default-sort -->
```

或

```vue
<!-- 方案 2：实现 onAppSortChange 函数对接 el-table 原生排序 -->
<script setup>
function onAppSortChange({ prop, order }) {
  if (prop === 'submittedAt') {
    appSortDir.value = order === 'ascending' ? 'asc' : 'desc'
    appList.search()
  }
}
</script>
```
