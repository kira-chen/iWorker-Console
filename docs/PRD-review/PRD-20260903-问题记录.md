## 【已解决】Q5. AI 生成规范三处矛盾（2026-09-06 按负责人要求大白话重写）

AI 生成按钮的规范文档《AI生成按钮Prompt规范.md》和各模块 md 有三处对不上，需要分别拍板：

**① 按钮放在哪里？**
- 专家 / MCP / API 的 md 写的是：**每个输入框旁边各放一个** AI 按钮，点一次生成 1 条；
- 规范文档和新原型写的是：**整个"示例问题"区只放一个**按钮，点一次一口气生成 3 条。
- demo 现在做的是后者（区级一个按钮、一次 3 条）。
- **需要你定**：按钮按"每行一个"还是"每区一个"。

**② 生成内容的字数上限打架。**
- 规范文档给 AI 生成内容定了通用上限（约 60 字）；
- 但岗位 SOP 的生成要求是"不超过 400 汉字"——SOP 是长文本，套 60 字上限会把内容截没。
- demo 现在 SOP 生成没有套 60 字限制（按 400 汉字口径）。
- **需要你定**：SOP 这类长文本是否豁免通用上限（即规范补一句"长文本场景按各自模块上限"）。

**③ 规范漏收了"业务系统"。**
- 业务系统的 md 里明确有 AI 生成按钮，但规范文档列举的 6 个使用场景里没有业务系统。
- demo 照业务系统 md 做了按钮。
- **需要你定**：把业务系统补进规范（或明确它不该有 AI 按钮）。

>决策：记入《PRD-20260904-md与原型一致性审查结果.md》，提交给产品经理浦月确认。

**✅ 2026-09-06 销项**：已记入审查结果文件第 14 条（三个子问题连同 demo 现状取舍一并移交）；demo 维持现状（区级按钮、SOP 按 400 汉字、业务系统保留按钮），待 PRD 侧统一后回流。
