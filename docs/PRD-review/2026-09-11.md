# 2026-09-11 改动记录

## 全站页头改为「标题 + 副文案」左右结构

**需求/问题**：负责人指示（附岗位管理页截图圈注）——页面标题与正文描述由上下结构改为左右结构，**所有页面都要改**。

**方案**：核查确认全站 25 个管理端页面**全部走共享组件** `components/PageHeader.vue`，无一处手写页头，故一处改即全站生效，无需逐页改造。改动仅两处 CSS：①`.page-header-text` 由默认块级堆叠改为 `display:flex + align-items:baseline + gap`，标题与副文案同行、基线对齐；**保留 `flex-wrap: wrap`**，窄屏副文案挤不下时自动折行，不硬挤两列。②`.page-header-sub` 去掉原 `margin-top`（纵向间距改由父容器 gap 承担，否则破坏基线对齐）。仅用语义令牌，无硬编码。

**影响面**：1 个共享组件（波及 25 个页面）；**vitest 149 文件 1838 条全绿、零断言改动**、build 通过。实走验证四种页头形态（纯标题+副文案 / 带操作按钮 / 带 emoji+徽标+作用域选择器 / 普通列表页）均同行渲染、基线对齐（标题 top 26 / 副文案 top 33、同行判定 true）、右侧操作区未被挤坏、零 console error。
